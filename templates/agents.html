A2A (Agent-to-Agent)

To call this agent from another agent, add it to the caller's a2a_access list in config.yaml.

# caller config.yaml
a2a_access:
  - "{{ agent.name }}"

MCP Usage

Assuming you have connected the Framework MCP Gateway, you can call this agent via the `use_agent` tool.

use_agent(agent_name="{{ agent.name }}", prompt="...")
