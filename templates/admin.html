Agent Memory

Master switch for per-agent persistent memory (Hindsight). When on, agents that opt in via agent_memory: true in their config will recall and retain context across sessions. Memory is shared across all users of a given agent unless per-user isolation is enabled below.

Per-User Memory Isolation

Scope agent memory to a private bank per user (agent:userid) instead of one shared bank per agent. Runs without a user identity (e.g. background workflows) keep using the shared bank. Existing shared banks are not migrated — isolation starts fresh per user.
