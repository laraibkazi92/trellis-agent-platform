Framework Connection Guide

Connect to MCP Gateway

Run this command to add Trellis directly to Claude Code:

claude mcp add --transport http trellis {{ public_mcp_url }} --header "Authorization: Bearer YOUR_API_KEY"

Or manually add this to your MCP configuration:

{
  "mcpServers": {
    "trellis": {
      "type": "http",
      "url": "{{ public_mcp_url }}",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

A2A (Agent-to-Agent)

To call this agent from another agent, add it to the caller's a2a_access list in config.yaml.

# caller config.yaml
a2a_access:
  - "{{ agent.name }}"

MCP Usage

Assuming you have connected the Framework MCP Gateway, you can call this agent via the `use_agent` tool.

use_agent(agent_name="{{ agent.name }}", prompt="...")
